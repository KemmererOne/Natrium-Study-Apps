The Reactor Core System is the set of replaceable core assemblies. This lesson covers each assembly type, reactivity control, and what the core must do in an event. PSAR Rev 1 (NAT-9400), Sec. 7.1.1, pp. 7.1-1 to 7.1-14

Purpose and arrangement

Objectives 1, 2

The RCC consists of replaceable core assemblies. It is contained within the RV and is supported and constrained by the Core Barrel Structures. PSAR Rev 1, ML25276A288, Sec. 7.1.1.1, p. 7.1-1

The reactor is a pool-type, sodium-cooled, fast reactor which operates at near-atmospheric pressure. PSAR Rev 1, ML25276A288, Sec. 7.1.1.1, p. 7.1-1

ParameterValue
Core power840 MWt PSAR Rev 1, ML25276A288, Sec. 7.1.1.5, p. 7.1-12
Inlet temperature at 100% power and flow680 F (360 C) PSAR Rev 1, ML25276A288, Sec. 7.1.1.5, p. 7.1-12
Outlet temperature at 100% power and flow950 F (510 C) PSAR Rev 1, ML25276A288, Sec. 7.1.1.5, p. 7.1-12
Core average fast flux fraction0.67 PSAR Rev 1, ML25276A288, Sec. 7.1.1.5, p. 7.1-12

The fuel pin

Objectives 3

The initial fuel is a sodium-bonded metal fuel in a tight, hex-packed pin bundle, with pins separated by a wire wrap. PSAR Rev 1, ML25276A288, Sec. 7.1.1.1, p. 7.1-3

The pin has shield slugs at the bottom, a sodium-bonded fuel column in the center, and a gas plenum with a tag gas capsule at the top, inside HT9 alloy steel cladding. PSAR Rev 1, ML25276A288, Sec. 7.1.1.1, p. 7.1-3

Cladding provides a functional containment barrier and resists plenum gas pressure and fuel swelling. PSAR Rev 1, ML25276A288, Sec. 7.1.1.1, p. 7.1-3

Tag gas identifies assemblies with failed fuel pins, using an online fuel monitoring system. PSAR Rev 1, ML25276A288, Sec. 7.1.1.1, p. 7.1-3

Reactivity control

Objectives 4

There are nine primary and four secondary control rod assemblies, which work with the CRD. PSAR Rev 1, ML25276A288, Sec. 7.1.1.3.1, p. 7.1-9

Absorber pins hold cladded, helium-bonded, boron carbide pellets. PSAR Rev 1, ML25276A288, Sec. 7.1.1.3.1, p. 7.1-10

Scram insertion has enough worth to shut down the reactor and maintain safe shutdown even with the highest worth rod stuck withdrawn. PSAR Rev 1, ML25276A288, Sec. 7.1.1.3.1, p. 7.1-10

Secondary control assemblies provide a regulating function to manage small reactivity changes. PSAR Rev 1, ML25276A288, Sec. 7.1.1.3.1, p. 7.1-10

Reactor power level, start-up, and shut-down are controlled by operator action. No operator action is required for the DL3 scram functions or to initiate natural circulation for emergency decay heat removal. PSAR Rev 1, ML25276A288, Sec. 7.1.1.3, p. 7.1-9

Inherent feedback

Objectives 6, 9

  • Fuel temperature (Doppler) effects
  • Fuel axial expansion and contraction
  • Primary sodium coolant density
  • Control rod driveline axial expansion
  • Radial distortion

PSAR Rev 1, ML25276A288, Sec. 7.1.1.2, p. 7.1-6

The net effect of the prompt acting feedbacks is negative in the power operating range. PSAR Rev 1, ML25276A288, Sec. 7.1.1.2, p. 7.1-6

The core restraint system maintains the core configuration for passive heat removal flow and for sufficient absorber insertion. PSAR Rev 1, ML25276A288, Sec. 7.1.1.2, p. 7.1-7

Instrumentation and indications

Objectives 5, 8

XIS senses neutron flux leaking from the core to indicate reactor power. PSAR Rev 1, ML25276A288, Sec. 7.1.1.5, p. 7.1-10

RIS monitors core temperature, neutron flux, coolant flow rate, and fuel failure through tag gas or coolant activity analysis. PSAR Rev 1, ML25276A288, Sec. 7.1.1.5, p. 7.1-10

RMS ensures radiation release from the core can be detected. PSAR Rev 1, ML25276A288, Sec. 7.1.1.5, p. 7.1-11

Safety significance and special treatment

Objectives 9, 10

The fuel assembly is classified safety-related. PSAR Rev 1, ML25276A288, Sec. 7.1.1.1, p. 7.1-2

The RCC supports scram function DL3-RC1 by keeping component movement within limits needed for control rod release. PSAR Rev 1, ML25276A288, Sec. 7.1.1.2, p. 7.1-7

The fuel assemblies maintain natural circulation capability and coolable geometry by limiting structural deformation. PSAR Rev 1, ML25276A288, Sec. 7.1.1.2, p. 7.1-7

  • Quality Assurance Program Description
  • Design Reliability Assurance Program
  • Equipment Qualification Program
  • Post-Construction Inspection, Testing, and Analysis Program

PSAR Rev 1, ML25276A288, Sec. 7.1.1.4, p. 7.1-10

Technical specification details for the core are not given in Sec. 7.1.1. See lesson OP-01.
