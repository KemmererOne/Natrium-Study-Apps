Control system terms

Objectives 1.1

"A control system is a system of integrated elements whose function is to maintain a process variable at a desired value or within a desired range of values." DOE-HDBK-1013/2-92 IC-07 p.2
"Automatic control systems neither replace nor relieve the operator of the responsibility for maintaining the facility." DOE-HDBK-1013/2-92 IC-07 p.1

If a control system fails, the operator must be able to take over and control the process manually. DOE-HDBK-1013/2-92 IC-07 p.1

"Control system input is the stimulus applied to a control system from an external source to produce a specified response from the control system." DOE-HDBK-1013/2-92 IC-07 p.2
"Control system output is the actual response obtained from a control system." DOE-HDBK-1013/2-92 IC-07 p.2
"An open-loop control system is one in which the control action is independent of the output." DOE-HDBK-1013/2-92 IC-07 p.6
"A closed-loop control system is one in which control action is dependent on the output." DOE-HDBK-1013/2-92 IC-07 p.3
"Feedback is information in a closed-loop control system about the condition of a process variable." DOE-HDBK-1013/2-92 IC-07 p.6
"A controlled variable is the process variable that is maintained at a specified value or within a specified range." DOE-HDBK-1013/2-92 IC-07 p.4
"A manipulated variable is the process variable that is acted on by the control system to maintain the controlled variable at the specified value or within the specified range." DOE-HDBK-1013/2-92 IC-07 p.4

Automatic control

Objectives 1.1

"An automatic control system is a preset closed-loop control system that requires no operator action." DOE-HDBK-1013/2-92 IC-07 p.4
  • Measurement
  • Comparison
  • Computation
  • Correction

DOE-HDBK-1013/2-92 IC-07 p.4

Three elements perform these functions: a measurement element, an error detection element, and a final control element. DOE-HDBK-1013/2-92 IC-07 p.4

"The measuring element performs the measuring function by sensing and evaluating the controlled variable." DOE-HDBK-1013/2-92 IC-07 p.5

The error detection element compares the controlled variable to the desired value and signals an error if there is a deviation. DOE-HDBK-1013/2-92 IC-07 p.5

"The final control element responds to the error signal by correcting the manipulated variable of the process." DOE-HDBK-1013/2-92 IC-07 p.5

Control loop diagrams

Objectives 1.2

A block diagram shows the cause and effect relationship between the input and output of a physical system. Arrows show signal flow. DOE-HDBK-1013/2-92 IC-07 p.7

A summing point shows addition and subtraction. A takeoff point allows a signal to be used by more than one block or summing point. DOE-HDBK-1013/2-92 IC-07 p.8

"the block diagram represents flowpaths of control signals, but does not represent flow of energy through the system or process." DOE-HDBK-1013/2-92 IC-07 p.9
"The plant is the system or process through which a particular quantity or condition is controlled." DOE-HDBK-1013/2-92 IC-07 p.10
"The control elements are components needed to generate the appropriate control signal applied to the plant." DOE-HDBK-1013/2-92 IC-07 p.10
"The feedback elements are components needed to identify the functional relationship between the feedback signal and the controlled output." DOE-HDBK-1013/2-92 IC-07 p.10
"The reference point is an external signal applied to the summing point of the control system to cause the plant to produce a specified action." DOE-HDBK-1013/2-92 IC-07 p.10

The reference point is also called the setpoint. DOE-HDBK-1013/2-92 IC-07 p.10

The feedback signal is a function of the output signal. DOE-HDBK-1013/2-92 IC-07 p.10

"The actuating signal represents the control action of the control loop and is equal to the algebraic sum of the reference input signal and feedback signal." DOE-HDBK-1013/2-92 IC-07 p.10

The actuating signal is also called the error signal. DOE-HDBK-1013/2-92 IC-07 p.10

"The disturbance is an undesirable input signal that upsets the value of the controlled output of the plant." DOE-HDBK-1013/2-92 IC-07 p.10

Example: lube oil cooler

Objectives 1.2

Cooling water flows in the shell around tubes that carry lube oil. DOE-HDBK-1013/2-92 IC-07 p.12

"The lube oil temperature is the controlled variable because it is maintained at a desired value (the setpoint)." DOE-HDBK-1013/2-92 IC-07 p.12
"Cooling water flow rate is the manipulated variable because it is adjusted by the temperature control valve to maintain the lube oil temperature." DOE-HDBK-1013/2-92 IC-07 p.12

If the temperature is above the setpoint, the controller moves the valve in the open direction, which sends more cooling water through the cooler. DOE-HDBK-1013/2-92 IC-07 p.12

The lube oil cooler is the plant, and the temperature transmitter is the feedback element. DOE-HDBK-1013/2-92 IC-07 p.12

The actuating signal passes through the temperature controller and the control valve. DOE-HDBK-1013/2-92 IC-07 p.13

Process time lags and stability

Objectives 1.3

"Process time lags are caused by three properties of the process." DOE-HDBK-1013/2-92 IC-07 p.13
"Capacitance is the ability of a process to store energy." DOE-HDBK-1013/2-92 IC-07 p.13
"Resistance is that part of the process that opposes the transfer of energy between capacities." DOE-HDBK-1013/2-92 IC-07 p.13
"Transportation time is time required to carry a change in a process variable from one point to another in the process." DOE-HDBK-1013/2-92 IC-07 p.13
"it is an actual time delay during which no change occurs." DOE-HDBK-1013/2-92 IC-07 p.13
"Stability is the ability of a control loop to return a controlled variable to a steady, non-cyclic value, following a disturbance." DOE-HDBK-1013/2-92 IC-07 p.13

Instability is caused by a combination of process time lags and time lags within the control system. DOE-HDBK-1013/2-92 IC-07 p.14

Decreasing amplitude oscillations eventually stop. DOE-HDBK-1013/2-92 IC-07 p.14

"This is the condition desired in an automatic control system." DOE-HDBK-1013/2-92 IC-07 p.14

Constant amplitude never reaches a stable condition. Increasing amplitude causes the process to go out of control. DOE-HDBK-1013/2-92 IC-07 p.15

Objectives 1.7

Valves that must be operated remotely and automatically need special devices to move them. DOE-HDBK-1013/2-92 IC-07 p.54

"These devices are called actuators." DOE-HDBK-1013/2-92 IC-07 p.54

A pneumatic actuator operates by a combination of force created by air and spring force. DOE-HDBK-1013/2-92 IC-07 p.54

"This "fail-safe" concept is an important consideration in nuclear facility design." DOE-HDBK-1013/2-92 IC-07 p.56

Summary

  • A control system maintains a process variable at a desired value or within a desired range. DOE-HDBK-1013/2-92 IC-07 p.6
  • Process time lags are affected by capacitance, resistance, and transportation time. DOE-HDBK-1013/2-92 IC-07 p.16
  • A two position controller has two operating conditions: completely on or completely off. DOE-HDBK-1013/2-92 IC-07 p.21
  • Proportional plus reset control eliminates any offset error that would occur with proportional control only. DOE-HDBK-1013/2-92 IC-07 p.36
  • Proportional plus rate control increases system stability but does not eliminate offset error. DOE-HDBK-1013/2-92 IC-07 p.42
  • The PID controller combines the three individual modes to achieve the advantages of each. DOE-HDBK-1013/2-92 IC-07 p.46
  • Actuators may be pneumatic, hydraulic, solenoid, or electric motor types. DOE-HDBK-1013/2-92 IC-07 p.60
