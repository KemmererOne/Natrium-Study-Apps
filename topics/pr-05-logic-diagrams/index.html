Why logic diagrams are used

Objectives 1.1

At DOE facilities, the main use of logic diagrams is to present component and system operational information. DOE-HDBK-1016/2-93 PR-05 p.1

"The use of logic symbology results in a diagram that allows the user to determine the operation of a given component or system as the various input signals change." DOE-HDBK-1016/2-93 PR-05 p.1
"The logic symbols, called gates, depict the operation/start/stop circuits of components and systems." DOE-HDBK-1016/2-93 PR-05 p.1

Once the basic symbols are understood, working out how the pump responds to its inputs from the logic diagram is fast and easy compared with tracing the relays and contacts of the schematic. DOE-HDBK-1016/2-93 PR-05 p.1

The basic gates

Objectives 1.1, 1.4

"There are three basic types of logic gates. They are AND, OR, and NOT gates." DOE-HDBK-1016/2-93 PR-05 p.4

Each gate is a simple device with only two states, on and off. DOE-HDBK-1016/2-93 PR-05 p.4

"The states of a gate are also commonly referred to as high or low, 1 or 0, or True or False, where on = high = 1 = True, and off = low = 0 = False." DOE-HDBK-1016/2-93 PR-05 p.4

The state of a gate, also called its output, is set by the status of its inputs. DOE-HDBK-1016/2-93 PR-05 p.4

"AND gate - provides an output (on) when all its inputs are on. When any one of the inputs is off, the gate's output is off." DOE-HDBK-1016/2-93 PR-05 p.4
"OR gate - provides an output (on) when any one or more of its inputs is on. The gate is off only when all of its inputs are off." DOE-HDBK-1016/2-93 PR-05 p.4
"NOT gate - provides a reversal of the input. If the input is on, the output will be off. If the input is off, the output will be on." DOE-HDBK-1016/2-93 PR-05 p.4

Because the NOT gate is often used with AND and OR gates, combinations have their own symbols. An AND gate with a NOT gate is a NAND gate. An OR gate with a NOT gate is a NOR gate. DOE-HDBK-1016/2-93 PR-05 p.4

"NAND gate - is the opposite (NOT) of an AND gate's output. It provides an output (on) except when all the inputs are on." DOE-HDBK-1016/2-93 PR-05 p.4
"NOR gate - is the opposite (NOT) of an OR gate's output. It provides an output only when all inputs are off." DOE-HDBK-1016/2-93 PR-05 p.4
"The IEEE/ANSI symbols are used most often; however, other symbol conventions are provided on Figure 3 for information." DOE-HDBK-1016/2-93 PR-05 p.4

COINCIDENCE and EXCLUSIVE gates

Objectives 1.1

Gates are not limited to two inputs, but the symbol must change as inputs are added. DOE-HDBK-1016/2-93 PR-05 p.5

"Theoretically, there is no limit to the number of inputs a gate can have." DOE-HDBK-1016/2-93 PR-05 p.5
"The COINCIDENCE gate behaves like an AND gate except that only a specific number of the total number of inputs needs to be on for the gate's output to be on." DOE-HDBK-1016/2-93 PR-05 p.6
"The fraction in the logic symbol indicates that the AND gate is a COINCIDENCE gate." DOE-HDBK-1016/2-93 PR-05 p.6
"The numerator of the fraction indicates the number of inputs that must be on for the gate to be on." DOE-HDBK-1016/2-93 PR-05 p.6

The denominator states the total number of inputs to the gate. DOE-HDBK-1016/2-93 PR-05 p.6

"Two variations of the OR gate are the EXCLUSIVE OR and its opposite, the EXCLUSIVE NOR." DOE-HDBK-1016/2-93 PR-05 p.6
"EXCLUSIVE OR - provides an output (on) when only one of the inputs is on. Any other combination results in no output (off)." DOE-HDBK-1016/2-93 PR-05 p.6
"EXCLUSIVE NOR - is the opposite (NOT) of an EXCLUSIVE OR gate's output. It provides an output only when all inputs are on or when all inputs are off." DOE-HDBK-1016/2-93 PR-05 p.6

Complex logic devices

Objectives 1.1

A memory device can remember the last command or position. DOE-HDBK-1016/2-93 PR-05 p.8

"The two input signals to a memory device are called set and reset." DOE-HDBK-1016/2-93 PR-05 p.8

A flip-flop is a device whose output changes as one or more of its inputs change. DOE-HDBK-1016/2-93 PR-05 p.9

"A flip-flop is a complex circuit constructed from OR and NOT gates, but is used so frequently in complex circuits that it has its own symbol." DOE-HDBK-1016/2-93 PR-05 p.9

A flip-flop is principally used in solid state logic diagrams (computers). DOE-HDBK-1016/2-93 PR-05 p.10

"Several types of binary counters exist, all of which are constructed of flip-flops." DOE-HDBK-1016/2-93 PR-05 p.10

A counter lets a computer count higher than 1, the highest number one flip-flop can represent. DOE-HDBK-1016/2-93 PR-05 p.10

"Shift register - Is a storage device constructed of flip-flops that is used in computers to provide temporary storage of a binary word." DOE-HDBK-1016/2-93 PR-05 p.10
"Half adder - Is a logic circuit that is used in computer circuits to allow the computer to "carry" numbers when it is performing mathematical operations" DOE-HDBK-1016/2-93 PR-05 p.10

Truth tables

Objectives 1.3

Truth tables help as the number of inputs and the complexity of a circuit grow. DOE-HDBK-1016/2-93 PR-05 p.11

"A truth table has a column for the input of each gate and column for the output of each gate." DOE-HDBK-1016/2-93 PR-05 p.11

The number of rows lists every combination of input signal. Mathematically it is 2 raised to the power n, where n is the number of inputs. DOE-HDBK-1016/2-93 PR-05 p.11

"In truth tables, the on and off status of the inputs and outputs is represented using 0s and 1s." DOE-HDBK-1016/2-93 PR-05 p.11
  • AND: output 1 only for inputs 1, 1
  • OR: output 0 only for inputs 0, 0
  • NOT: input 0 gives 1, and input 1 gives 0
  • NAND: output 0 only for inputs 1, 1
  • NOR: output 1 only for inputs 0, 0
  • EXCLUSIVE OR: output 1 for inputs 0, 1 and 1, 0

DOE-HDBK-1016/2-93 PR-05 p.12

"The symbol is drawn so that the first part of the square wave indicates the normal state of the gate." DOE-HDBK-1016/2-93 PR-05 p.13

Objective 1.5

Fan start circuit: identify and time

Identify the AND, OR, time delay, and retentive memory symbols. How long must the safety signal be present before the time delay passes an on signal to Gate 2?

  1. Use the numbers on the drawing: AND is 2, OR is 3, the time delay is 1, and the retentive memory is 4.
  2. The time delay is marked 10 MINUTES.

Answer: The safety signal must be received for greater than 10 minutes. If it is removed sooner, no signal is passed to Gate 2.

DOE-HDBK-1016/2-93 PR-05 p.18

Objective 1.5

Fan start circuit: Gate 2 and the alarm

When does Gate 2 turn on, and when does the low flow alarm sound?

  1. Gate 2 is an AND gate, so both of its inputs must be on.
  2. The alarm follows the 45 second delay and flow switch 30-38, or the same condition on the 1B-B fan.

Answer: Gate 2 turns on when the hand switch is in AUTO and a safety signal has been received for greater than 10 minutes. The alarm sounds if FS 30-38 senses less than 20,000 cfm 45 seconds after the fan has started, or the same condition exists on the 1B-B fan.

Objective 1.5

Fan start circuit: losing the safety signal

Twelve minutes after first receiving a safety signal, with the switch in AUTO, the safety signal is removed. What happens to the fan?

  1. The fan started ten minutes after the safety signal.
  2. Removing the safety signal removes only the continuous start signal.
  3. The retentive memory keeps the fan on until a STOP signal.

Answer: The fan continues to run until the hand switch is placed in the stop position.

DOE-HDBK-1016/2-93 PR-05 p.18

Objective 1.5

Fan start circuit: ways to start and stop

How many ways can the fan be started and stopped?

  1. Start: the START signal through OR gate 3, or AUTO plus the safety signal through Gate 2.
  2. Stop: the STOP signal to the memory.

Answer: It can be started by two signals, START and AUTO plus a safety signal. It can be stopped by one signal, STOP, but will only remain stopped if no safety signal is present or the switch is held in the stop position.

DOE-HDBK-1016/2-93 PR-05 p.18

Objective 1.5

Valve circuit: status at Gate 4

With the hand switch in AUTO and no safety signal, what is the status of the two inputs to Gate 4?

  1. Right input: the CLOSE contacts are open, so the signal is off. The NOT gate reverses it to on.
  2. Gate 1: the safety NOT input is on and AUTO is on, but the fully open signal is off, so Gate 1 is off.
  3. Gate 2: the OPEN signal is off and Gate 1 is off, so Gate 2 is off.

Answer: The right input is on and the left input is off.

DOE-HDBK-1016/2-93 PR-05 p.18

Objective 1.5

Valve circuit: is the solenoid correct?

Electrical components are drawn de-energized. Is FSV-1-147 in its correct position, and how many ways can it be energized and de-energized?

  1. Gate 4 is an AND gate with one input off, so it passes no on signal.
  2. The hand switch in OPEN momentarily energizes it.
  3. CLOSE de-energizes it, and so does a safety signal once the valve is open.

Answer: Yes, de-energized is correct. It can be energized one way, by the OPEN position. It can be de-energized two ways, by the CLOSE position or by a safety signal with the valve open.

DOE-HDBK-1016/2-93 PR-05 p.19

Objective 1.5

Valve circuit: opening with a safety signal

If a safety signal is present, can FCV-1-147 be opened?

  1. The OPEN position passes through OR gate 2 directly.
  2. When the switch returns to AUTO, the safety signal's NOT gate removes the on signal to Gate 1.

Answer: Yes, it can be opened, but it will not remain open when the hand switch spring returns to AUTO.
